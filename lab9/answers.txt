When height is 1, L1 miss rate was 1.15% and LLC miss rate was around 72%. When height was 10000, L1 miss rate was 8.79% and LLC miss rate was 13%.
Yes this matches my expectations. With a larger height we're accessing memory in column-wise order with big jumps between elements,
so the L1 cache gets thrashed. The L1 misses went up around 7.6 times with the LLC miss rate actually went down because more of the working set fits in the larger L3 cache.
even though we're missing L1 more often.
